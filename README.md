# Iman Academy

A gamified way for families to learn Islam: a step-by-step Hanafi prayer guide,
prayer times, a qibla finder, topic quizzes, and ten badges on the Path of Light.

Built on the same stack as Digital Workspace (Tizmo): **Next.js 14 (App Router) +
TypeScript + Tailwind**, **Prisma on Supabase Postgres**, deployed on **Vercel (fra1)**.
Works on phones, tablets and desktop, with light, dark and system themes.

## What's built (Phase 1)

- **Home** — next prayer with live countdown, badge progress, continue learning.
- **Salah** — wuḍūʾ guide and every prayer (Fajr, Dhuhr, Asr, Maghrib, Isha, Witr,
  Jumuʿah), each sunnah/farḍ/witr unit walked through step by step: posture figure,
  Arabic, transliteration, meaning, farḍ/wājib/sunnah tag, and men/women notes.
  Steps are generated by `buildSteps()` in `src/content/prayers.ts`.
- **Times** — calculated prayer times (Hanafi Asr), city list or "Use my location",
  five Fajr/Isha methods, Hijri date, rakʿah summary per prayer.
- **Qibla** — bearing and distance to the Kaʿbah, with a live compass on phones.
- **Ilm Quest (Knowledge Base)** — 7 worlds and 31 lessons: Iman, Islam (5 pillars),
  Salah Academy, Akhlaq & Adab (five-part lessons: why it matters, how to do it right,
  benefits, what we lose, practice), Daily Duas, Quran Basics and Seerah.
- **Quizzes** — 5 topics × 10 questions, each with an explanation and a source.
- **Ramadan Quest** — Hijri countdown, private daily tracker (fast, prayers, taraweeh,
  Quran pages, dhikr, sadaqah, reflection), khatm planner, make-up fast tracker,
  30-day Quest, labelled Ramadan duas, surahs and history.
- **Mizan** — dhikr, character, duas and surahs heaviest on the scale, with source and
  grade, filters, a private routine and counter, and a Myth Check section.
- **Badges** — 10 badges, one per 1,000 points. Points come from learning only;
  worship is never scored.

Progress is saved in the browser for now (guest mode). The Prisma schema for
accounts, family circles and synced progress is in `prisma/schema.prisma`.

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
```

The app runs without a database in Phase 1. For Phase 2, copy `.env.example`
to `.env`, fill in the Supabase URLs, and run `npm run db:push`.

## Project layout

```
src/
  app/            pages: / learn learn/[world] learn/[world]/[lesson] quiz/[topic]
                  salah times qibla ramadan mizan badges more
  components/     app shell, theme toggle, progress store, figures, pickers
  content/        library (worlds), adab lessons, mizan, ramadan, recitations,
                  prayers + step builder, quiz topics, cities, badges
  lib/            prayer-time and qibla math, hooks
prisma/           database schema (Phase 2)
```

## Before public release

- A qualified Hanafi scholar must review every lesson, question and Arabic string
  (`src/content/`). Verify Arabic against a printed mushaf.
- In Uzbekistan, compare calculated times with the Muslim Board of Uzbekistan
  calendar and pick the matching method.
